## ปัญหาสำคัญของของเดิมที่ SABAii หลีกเลี่ยง

1. โหลด JS 3.4 MB + CSS 2.2 MB ตอนเปิด → SABAii โหลดเฉพาะที่ต้องใช้ (รวมทั้งแอปราว 240 KB ไม่บีบอัด ในนั้นตัวแกะข้อความ 121 KB · ไม่นับฟอนต์ · ยังไม่ได้วัดความเร็วจริง)
2. ตัวแกะเดิมเติม 23:59 / 08:00 ให้เองเมื่อไม่ได้บอกเวลา → SABAii ทิ้งเวลานั้นและติดป้าย "ไม่ระบุเวลา" (สเปก 3.1, 5.3)
3. วันที่เก็บเป็น ISO (UTC) → SABAii เก็บเป็น `YYYY-MM-DD` + `HH:MM` ของเครื่อง กันวันเลื่อน (สเปก 5.4)

## ข้อที่สเปกขัดกับ repo และที่ตัดสินไปแล้ว

| เรื่อง | สเปก | ที่ทำ | ใครตัดสิน |
|---|---|---|---|
| ที่วางแอป | branch แยกจาก production | repo แยกของตัวเอง (SABAiiz/SABAii) | เจ้าของ: "ทำเป็น local ก่อน" |
| Stack | แนะนำ React + TS + Vite | JS ล้วน ES modules ไม่มี build | เจ้าของให้ผมเลือก — repo นี้ห้าม npm/build และ GitHub Pages ขึ้นไฟล์ตรง ๆ |
| หน้างาน | รายการ + ตัวกรอง สลับปฏิทิน | ลิ้นชักวิชา + ตัวกรอง 5 แบบ + ปุ่มปฏิทินขยายได้ | รวมทั้งสเปกและภาพที่เจ้าของเลือกรอบก่อน — **ยังรอเจ้าของยืนยัน** |
| ข้อมูลเดิม | ห้ามทำลาย | เริ่มใหม่ + ปุ่มนำเข้าแบบอ่านอย่างเดียว | เจ้าของ |
