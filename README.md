## โครงสร้าง

```
  index.html  manifest.webmanifest  sw.js  icon.svg
  src/
    main.js            เปิดแอป · เส้นทาง (#/home #/tasks #/me #/subject/<id>) · เมนูล่าง
    domain/            กฎล้วน ไม่แตะ DOM — dates · tasks · thai-parse (ตัวแกะข้อความไทยของ SABAii) · parse
    data/              db (IndexedDB / หน่วยความจำ) · store (สถานะ + บันทึก)
    ui/kit.js          สร้าง DOM · ไอคอน · ข้อความลอย · กล่องล่าง (กันข้อความหาย + ปุ่มย้อนกลับ) · กล่องยืนยัน · ป้ายวิชา
    features/          shared · home (แผ่นล่าง + ชั้นโน้ต) · add (เพิ่มงาน/โน้ต/แก้ไข/ภาพย่อ) · tasks (หน้างาน + หน้าวิชา) · me · voice · images
    styles/app.css
  tests/               core.test.mjs (node) · e2e.cjs · shell.e2e.cjs · shell-ride.e2e.cjs (Playwright)
  shell/               ต้นแบบที่ใช้ตัดสินใจหน้าตา 0.4 (ข้อมูลตัวอย่าง แยกจากแอป) · shell/ride/ = โครงแอปเรียกรถต้นฉบับ
  docs/PHASE0-AUDIT.md · screens-*.png
  mockups/            ภาพเสนอการออกแบบ (HTML + PNG)
```

ไม่มี npm ไม่มีขั้นตอน build — ไฟล์ไหนแก้แล้วรีเฟรชเห็นเลย ย้ายไปบัญชี/โฮสต์อื่นได้ด้วยการก๊อปโฟลเดอร์นี้ทั้งโฟลเดอร์
ข้อมูลผู้ใช้อยู่ใน IndexedDB ชื่อ `sabaii` · สำรอง/กู้คืนเป็น JSON ของ SABAii เอง (ไม่รวมรูป)
**แก้ไฟล์ในแอปเมื่อไหร่ ต้องขึ้นเลข `CACHE` ใน `sw.js`** ไม่งั้นเครื่องที่เคยเปิดจะได้ไฟล์เก่า
