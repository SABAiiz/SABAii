## โครงสร้าง

```
  index.html  manifest.webmanifest  sw.js  icon.svg
  src/
    main.js            เปิดแอป · เมนูล่าง 3 หน้า (#home #tasks #me)
    domain/            กฎล้วน ไม่แตะ DOM — dates · tasks · thai-parse (ตัวแกะข้อความไทยของ SABAii) · parse
    data/              db (IndexedDB / หน่วยความจำ) · store (สถานะ + บันทึก)
    ui/                dom (ตัวช่วย + ไอคอน + toast + กล่องยืนยัน) · sheet (แผ่นล่าง)
    features/          add · detail · views · voice · images
    styles/app.css
  tests/               core.test.mjs (node) · e2e.cjs (Playwright)
  docs/PHASE0-AUDIT.md · screens-0.3.png
  mockups/            ภาพเสนอการออกแบบ (HTML + PNG)
  shell/              โครงแอปแบบเรียกรถ (แผนที่ + แผ่นล่าง 3 ระดับ + ขั้นตอนเรียกรถ) ไว้ต่อยอด — ดู shell/README.md
```

ไม่มี npm ไม่มีขั้นตอน build — ไฟล์ไหนแก้แล้วรีเฟรชเห็นเลย ย้ายไปบัญชี/โฮสต์อื่นได้ด้วยการก๊อปโฟลเดอร์นี้ทั้งโฟลเดอร์
ข้อมูลผู้ใช้อยู่ใน IndexedDB ชื่อ `sabaii` · สำรอง/กู้คืนเป็น JSON ของ SABAii เอง
**แก้ไฟล์ในแอปเมื่อไหร่ ต้องขึ้นเลข `CACHE` ใน `sw.js`** ไม่งั้นเครื่องที่เคยเปิดจะได้ไฟล์เก่า
