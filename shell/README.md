# shell/ — โครง SABAii บนกลไกแบบแอปเรียกรถ

เจ้าของสั่ง 17 พ.ย. 69: "ก็อป Bolt มาทำเป็นโครงของเราเองก่อน" → `shell/ride/` (โครงเรียกรถ)
แล้ว "ลองเปลี่ยนเป็นแบบนี้" (ภาพหน้าแรก · ดึงลงดูโน้ต · หน้างาน+ปฏิทิน) → `shell/` (โครง SABAii)
เขียนใหม่ทั้งหมด ไม่ใช้โลโก้ ชื่อ ภาพ หรือโค้ดของ Bolt · ใช้ตัวแกะข้อความไทยของ SABAii (`src/domain/`)

เปิดดู: `python3 -m http.server 8765` → `http://localhost:8765/shell/` (โครงเรียกรถ: `/shell/ride/`)
เทสต์: `node tests/shell.e2e.cjs` (23/23) · `node tests/shell-ride.e2e.cjs` (14/14) — ไม่ต้องเปิดเซิร์ฟเวอร์

| แอปเรียกรถ | SABAii (shell/) |
|---|---|
| แผนที่เต็มจอด้านหลัง | **โน้ตหน้างาน** — 1 หน้า = 1 งาน เรียงเหมือนหน้าแรก · ปัดขึ้น/ลง = งานถัดไป · ปัดซ้าย/ขวา = โน้ตถัดไป (กระดาน · ใบงาน · กระดาษโน้ต · รูป) |
| แผ่นล่าง "ไปไหน?" | แผ่นล่าง = หน้าแรก: เพิ่มงาน 4 แบบ (พูด/แนบรูป/พิมพ์/ถ่ายรูป) · ค้นหา + ชิปวัน · งานแนะนำเรียงตามกำหนดส่ง |
| ดึงแผ่นลงดูแผนที่ | ดึงลง (หรือแตะ "ทำเลย") → แผ่นเหลือการ์ดงาน: เพิ่มโน้ต รูป/ข้อความ/เสียง + **ทำเลย** (จับเวลา) → **เสร็จแล้ว** (เลิกทำได้) |
| แถบเมนูล่าง | ลอยเป็นเม็ดยา · **หลบเอง** ตอนดูโน้ต และตอนเลื่อนรายการลง โผล่กลับตอนเลื่อนขึ้น |
| — | หน้า **งาน**: ปฏิทินเปิด/ปิด (2 สัปดาห์ ↔ ทั้งเดือน · ลากแถบลง/ขึ้นได้) จุดแดง = สอบ จุดฟ้า = งานส่ง · แตะวัน = รายการวันนั้น · ตัวกรอง · **การ์ดโปรเจกต์ต่อวิชาแบบ Canva** (ภาพย่อจากโน้ตจริง) → หน้าวิชา: ทุกงาน + แถบโน้ต + เพิ่มโน้ต |
| — | หน้า **ฉัน**: ชื่อ · สรุป 3 ช่อง · ธีมมืด · รีเซ็ตตัวอย่าง |

ข้อมูลอยู่ใน `localStorage` คีย์ `sabaii-shell-v1` (แยกจากฐานข้อมูลแอปหลัก) · เริ่มด้วยงานตัวอย่าง 7 งาน วันที่คิดจากวันนี้

## ยังไม่ได้ทำ / ข้อจำกัด
- ไม่มี OCR อ่านรูป (ผู้ใช้พิมพ์ชื่องานเอง) · พูดใช้ Web Speech ของเบราว์เซอร์ (เครื่องที่ไม่รองรับจะสลับไปพิมพ์)
- ลองแค่ Chromium จอ 390×844 ด้วยเมาส์ — **ยังไม่ได้ลองนิ้วบนมือถือจริง** · ตอนแผ่นเต็มจอ บนจอสัมผัสต้องลากที่จับเพื่อดึงลง
- ยังไม่ได้ย้ายเข้าแอปหลัก (`index.html` + `src/`)
