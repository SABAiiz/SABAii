# shell/ — โครงแอปแบบเรียกรถ (ต้นแบบโครง ไม่ใช่ SABAii)

ทำตามที่เจ้าของสั่ง 17 พ.ย. 69: "ลองก็อปแล้วสร้าง Bolt แบบของพวกเราเองก่อน จะได้มีโครง"
→ ถอด **โครงและการทำงาน** ของแอปเรียกรถแบบ Bolt มาเขียนใหม่เองทั้งหมด · **ไม่ได้ใช้โลโก้ ชื่อ สี ฟอนต์ ภาพ หรือโค้ดของ Bolt**
ใช้สี/ฟอนต์ชุดเดียวกับ SABAii (`src/styles/app.css`) เพื่อย้ายชิ้นส่วนไปใช้ได้ทันที

เปิดดู: `python3 -m http.server 8765` แล้วเปิด `http://localhost:8765/shell/`
เทสต์: `node tests/shell.e2e.cjs [โฟลเดอร์เก็บภาพ]` (ไม่ต้องเปิดเซิร์ฟเวอร์) — 14/14 ผ่าน 17 พ.ย. 69

## มีอะไรบ้าง

| ชิ้น | ทำงานอย่างไร | ใช้กับ SABAii ได้ไหม |
|---|---|---|
| แผนที่เต็มจอ (SVG วาดเอง) | ลากเลื่อน · ล้อเมาส์/สองนิ้วซูม · รถวิ่งประกอบฉาก · กล้องเลื่อนให้พอดีเส้นทางโดยเว้นส่วนที่แผ่นล่างบัง | → "แผนที่เวลา" (`mockups/sabaii-map.png`) แกนตั้ง = ชั่วโมง แกนนอน = วัน |
| แผ่นล่าง 3 ระดับ | ต่ำ · กลาง · เต็ม · ลากตามนิ้ว/เมาส์ + ปัดเร็วข้ามระดับ · แตะที่จับ = สลับ · ปุ่มด้านล่างอยู่ในจอเสมอ | → แทน `src/ui/sheet.js` ได้ (ตัวนี้ลากได้ทั้งแผ่น ไม่ใช่แค่ที่จับ) |
| แถบค้นหาก้อนใหญ่ + ชิปเวลา | "ไปไหนดี?" + "ตอนนี้ ▾" เปิดกล่องเลือกเวลา | → "จะทำงานไหน?" + "วันนี้ ▾" |
| ค้นหา + กรองสด + เลือกบนแผนที่ | หมุดกลางส่วนที่มองเห็น ชื่อจุดเปลี่ยนตามที่เลื่อน | → เลือกวัน/เวลาส่งบนแผนที่เวลา |
| ขั้นตอนหลายหน้า + ปุ่มย้อนกลับของเครื่อง | สแตกหน้า + `history` · ระหว่างเรียกรถห้ามย้อน ต้องกดยกเลิก | → เพิ่มงาน → ตรวจสอบ → บันทึก |
| เลือกรถ / คนขับ / เดินทาง / ให้คะแนน | ราคา-เวลาคิดจากความยาวเส้นทาง · รถวิ่งตามเส้นจริง | → เริ่มทำงาน → จับเวลา → เสร็จ → สรุป |
| ลิ้นชักเมนู · ธีมมืด · ข้อความลอย | | ใช้ได้ตรง ๆ |

## ยังไม่มี / จำลองทั้งหมด

แผนที่จริง · GPS · บัญชี · จ่ายเงิน · คนขับจริง · โทร/แชต — ปุ่มเหล่านี้ขึ้นข้อความ "ยังไม่ทำในโครงนี้"
ยังไม่ได้ลองบนมือถือจริง (ลองแค่ Chromium จอ 390×844 ด้วยเมาส์) · ตอนแผ่นเต็มจอ บนจอสัมผัสต้องลากที่จับเพื่อย่อ
